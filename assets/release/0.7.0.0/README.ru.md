# CLAW - Configurable Lycanthrope Anatomy and Weight

Релиз 0.7.0.0 (31 октября 2026): выразительные морфы мужского и женского тела и
матрицы преобразования человеческих морфов в морфы оборотня. DLL, тела, скрипты,
плагины и таблицы преобразования совпадают с проверенными 31 октября в Skyrim SE.
Владелец подтвердил видимые различия всех шести сравнительных пресетов. Это
подтверждение контраста; пропорции, грудь, цвет шерсти и другие детали внешности
продолжают дорабатываться.

**Для этого релиза обязательны мужские тела HIMBO и женская база CBBE.**
Женский вариант — CBBE либо CBBE с расширением 3BA; для 3BA также нужна CBBE.
Установите тела со всеми заявленными авторами зависимостями отдельными модами.
Поддержка ванильных человеческих тел отложена в бэклог и в этот релиз не входит.

Установите архив через менеджер с поддержкой FOMOD. Ресурсы оборотня и связь
с человеческими морфами обязательны; варианта установки только базы нет.
Укажите ровно одно установленное сочетание: **HIMBO + CBBE** либо
**HIMBO + CBBE + 3BA**. Эти варианты содержат таблицы преобразования, а не
человеческие тела или пресеты. При активном `3BBB.esp` установщик рекомендует
3BA, иначе — CBBE. Без активного маркера вариант 3BA недоступен. Выбор виден и
редактируется: даже при активном маркере 3BA можно выбрать CBBE, если этого
требуют фактически выигрывающие меши. При смене семейства тел переустановите
CLAW; для ранее сохранённых профилей актёров при необходимости выполните явное
повторное назначение. Необязательный вариант
**Originally-beast OBody source integration** получает через OBody человеческие
исходные значения для актёров, впервые встреченных уже оборотнями.

Отдельно нужны текстуры Elegant Werewolf Replacer и совместимый скелет XP32;
меши CLAW должны выигрывать конфликты. Морфам и DLL нужны SKSE, RaceMenu/SKEE и
Address Library для вашей версии игры, а также Microsoft Visual C++ x64 Runtime.
Для дополнительного источника OBody
нужен сам OBody со всеми его зависимостями. Установщик требует активные маркеры
`HIMBO.esp`, `CBBE.esp` и `RaceMenu.esp`, а для дополнительного источника проверяет
`OBody.esp`. Это проверка включённых плагинов: она не доказывает, какие меши
выигрывают конфликты, совместимость DLL и полноту зависимостей. Видимый выбор
тел задаёт используемое преобразование. Общие пути мешей не служат определением
тела; совместимость версии игры установщик не определяет.

Архив содержит одну DLL CommonLib для заявленных границ загрузки SE, AE и VR.
Игровые проверки механизма пройдены только в **Skyrim SE 1.7.104.0 / SKSE 2.3.1**
с официальным RaceMenu и HIMBO/3BA. Для других версий SE/AE, VR и варианта CBBE
сохранены только проверки вне игры. Базовый плагин имеет флаг light; его загрузка
и зависимости в VR не проверены. Точные версии и ограничения перечислены в
[описании DLL](Docs/universal-runtime.md), результаты — в
[отчёте проверок](Docs/verification-20261031.md).

Три существующих расчётных XML-профиля HIMBO, CBBE и 3BA остаются отдельными.
Установщик не вводит единую матрицу и не меняет расчёты.
Пресет волка задаёт матрицу преобразования; полностью постоянная матрица задаёт
независимого волка. Ранее сохранённые матрицы сохраняют силу до явного повторного
назначения. Нейтральные низкий и высокий весовые меши одинаковы внутри каждого
пола. Подробнее: [матрицы](Docs/matrix-contract.md) и
[рецепт тела](Docs/expressive-body.md).

Тестовые актёры, человеческие тела, текстуры, скелет, физика и тело VR от первого
лица сюда не входят. Дополнительный `test_CLAW` устанавливается отдельно только
для проверки. Бельё для скриншотов и освещение относятся к тестовой сцене и
зависимостям человеческих тел. Авторы исходной работы Elegant: Wolflady500 и
KaienHash.

В `Source/` находятся соответствующие исходники и инструкции пересборки;
в `NOTICES/` — лицензии и сведения об авторах. Установщик не копирует эти
каталоги в игру. Не копируйте все каталоги архива в Data вручную.

## Изменения относительно Nexus 0.6.2.0

* Человеческие морфы определяют форму оборотня каждого актёра. Предусмотрены
  матрицы для HIMBO, CBBE и 3BA; источником остаются обычные человеческие пресеты.
* Добавлены худые формы и усилены объёмные. Включены исправления мужского шва
  у воротника и женской груди/подмышки.
* Дополнительный источник OBody обслуживает новых актёров, изначально появившихся
  оборотнями, сохраняя правила назначения и исключения самого OBody.
* Все рабочие компоненты объединены в один FOMOD с одной универсальной DLL.
  Физика и VR-тело от первого лица остаются задачами следующих версий.

Для обновления замените прежнюю установку CLAW этим архивом через менеджер и
укажите используемые человеческие тела. Зависимости остаются отдельными модами.
Ранее сохранённые матрицы экспериментальных native-версий сохраняют силу:
переустановка XML сама по себе не переназначает профили существующих актёров.
Номер пакета относится ко всему релизу. Внутренние идентификаторы DLL и тел
описывают проверенные входные сборки; игровые файлы ради номера пакета не
перекомпилировались и не перемаркировывались.
