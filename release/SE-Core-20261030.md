# SE core Git release baseline — 30 October 2026

The owner requested a release freeze after inspecting the paired human/wolf
scene in Skyrim SE. The exact Base and Distribution payloads are retained in
`assets/release/se-core-20261030/`, with a per-file manifest and the matching
native corresponding-source archive. The date identifies this Git baseline;
the original tested packages retain their candidate metadata. No Nexus upload
or publication follows from this source-control checkpoint.

This baseline includes repaired body resources and deterministic human-to-wolf
linkage using ordinary human OBody presets. Both sexes, transformation/return,
human-key preservation, save/load and originally-beast assignments passed the
documented 117-check and 33-check SE runs. Official RaceMenu is used unchanged.
See [verification](../docs/verification-20261030.md).

The owner still finds the rendered wolf differences too weak. Numeric diversity
does not establish visible diversity: neutral limbs remain bulky, negative lean
inputs cannot produce a thinner endpoint, and the fur envelope hides part of
the skin deformation. These are acknowledged limits of the frozen result.
Breast naturalness, stronger thin/bulky endpoints, fur colour and physics belong
to subsequent development. Physics, VR and untested executable versions receive
no new compatibility claim.
