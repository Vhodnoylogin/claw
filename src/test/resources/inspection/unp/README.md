# Classic UNP technical lifecycle fixture

This nonshipping contract checks the manual `CLAW.UNP.4.6.Weight1` selection
against the original UNP Female Body Renewal 4.6 resources. It introduces no
human presets, invented UNP sliders, new NPC plugin or duplicate test framework.
The shared inspection kit supplies the room, two existing female NPC bases and
the accepted placement/AI/collision conventions.

The names Thin and Heavy identify existing test roles, not proof of actual NPC
weight. Read both weights before transformation and require a measured
difference. An unavailable query or equal weights blocks this fixture's weight
comparison; it must not be repaired by inventing values or using an unqualified
setter. The same actors provide their own human baselines.

Prove the actual body/hand/foot VFS winners from the original archive. A checked
UNP installer option while a CBBE/3BA/BHUNP generated output wins is insufficient.
Renewal has fixed weight endpoints and no runtime body TRI; an empty ordinary
SKEE map is valid, while a failed query is not an empty map. OBody assignment and
the originally-beast host are unnecessary for this weight-only body contract.

Compare the complete observed female wolf vector with the same shared native
evaluator used by the game, using actual weight and available generic traits.
Counterfactual checks separately establish ordinary-key noninterference and
weight influence without confusing differences in head traits with body weight.
Then refresh, save/load, return and retransform the two owned references while
checking source preservation. No texture/art/physics acceptance is required.

`scenario.json` is a portable fixture and collection contract, not a launchable
order. Keep compiled files, actual installation selections, tool bindings,
reference IDs, saves and raw results outside Git. Prepare and admit execution
only after the current environment owner releases the live installation.
