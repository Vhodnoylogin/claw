# BHUNP technical inspection fixture

This is portable, nonshipping test source for the HIMBO/BHUNP matrix selection.
It supplements the historical HIMBO/3BA paired inspection kit without changing
that kit's presets or recorded equality. It is not a save or a ready live order.

`CLAW-BHUNP-Technical.xml` is the authoritative authored source for three ordinary
human BodySlide presets. Each declares all 47 mapped BHUNP source keys at both
endpoints, including nonzero Low/High controls. These are technical Slim,
Muscular and Heavy vectors, not renamed CBBE/3BA presets or an artistic claim.
The matching ordinary keys were checked against the actual BHUNP 3.34 Advanced
Ver4 OSD and officially generated NeverNude TRI. XML percentages are preset
inputs; use actual measured OBody/SKEE values when evaluating a running actor.

The preset project name `BHUNP 3BBB Advanced Ver2 Nevernude` is the author's
historical name. Its core slider data resolves to the Ver4 body datasets. The
generated body, underwear maps, compatible UNP skin and BHUNP source mod are
external dependencies; none is bundled in this source fixture or CLAW's runtime.

`OBody_presetDistributionConfig.json` retains the complete twelve human/wild base
mappings and unrelated race blacklists. Its male presets come from the existing
HIMBO fixture; only the female mappings/pool use these three BHUNP presets.
Install it only as an isolated test-profile override, never as a playthrough
distribution policy. It does not manually assign values to any live reference.

`scenario.json` records six initially human actors, their accepted wolf-slot
positions relative to the same room, and the lifecycle checks. Each actor
supplies its own human baseline; no twins are created for this technical case.
Establish AI and collision Off before creation and retain the explicit position
hold. Save/load requires six distinct owned references, not six distinct bases.
Plugin/local form IDs are source identifiers; resolve them and fresh references
through the qualified adapter rather than copying a session load-order prefix.

The existing fixture builder and inspection kit remain the source of shared
scene/body/preset conventions. No second generic fixture framework or generated
preset copy is introduced: this XML and the existing male XML are authored inputs.
For a separate `test_CLAW` package, use the two explicit resource mappings in
`scenario.json` with the established source-pinning and archive-verification
workflow. Keep machine paths, adapter bindings, tokens, orders, compiled plugins,
generated human bodies, logs and actual game evidence outside Git.

Legacy source-enumeration snapshots are not mathematical acceptance of the
current sparse/nonlinear matrix. Compare all 30 male/31 female wolf outputs
against the shared native evaluator using the same actor's measured source keys,
weight and available typed traits. Native offline checks and this source fixture
do not themselves establish an installed-game result. Finish through the game
menu and verify full restoration before accepting a run.
