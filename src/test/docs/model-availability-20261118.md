# Required wolf model: bounded source correction

Tags: CLAW, model availability, native regression

The [Bijin compatibility record](bijin-npcs-20261118.md) separates successful
coefficient readback from the absent wolf-model evidence in unpatched custom
skins. A private fourteen-skin addon patch subsequently yielded fifteen actual
wolf geometries with unchanged mathematics and resources. That game evidence
qualifies the optional patch's tested NPCs, not this later native correction.

The source now requires a completed bounded third-person graph observation with
one actual geometry for each authored role `body`, `head`, `claws`, `fur_tailtip`
before reporting status 2. The adapter uses engine name identity, including
observed uppercase `BODY`/`HEAD`. Missing/ambiguous roles and collection failure
report existing error 4 and remain dirty for the next ordinary refresh; context
turnover remains pending. An unchanged skeleton root cannot retain a negative
observation after parts arrive or bypass observation after parts disappear.
Human return and explicit cleanup keep their existing branches and statuses.

The finite role contract was checked read-only through PyNifly in both sexes and
both weight endpoints from the pinned 0.10 runtime inputs. All four meshes have
exactly one geometry for each required role. The external receipt is
`Builds/claw-bijin-game-20261118/model-availability-review-02/authored-role-verification.json`;
it records resource hashes and original input provenance. No vendor or generated
mesh was added to source.

`TargetModelAvailabilityTests.cpp` exercises actual bounded traversal over fake
graphs: geometry types, case-equivalent identity, missing/duplicate roles, the
inclusive 512-object/64-geometry bounds, queued work, sparse child slots, cycles,
same-root arrival/removal and stale context. Its view cases retain healthy world
models with absent/partial first-person graphs and reject combining roles across
views. Existing VR part/lifecycle, request ownership, morph, material and source
bootstrap suites remain separate. No nonzero coefficient, coat success or
BODYTRI marker is used to establish geometry presence.

A failed completed missing/ambiguous observation also revokes an engaged physics
authority through its existing model rejection and revision. Fresh role checks
fence physics registration, observation/reapplication, queued-fit completion and
publication even when skeleton/part pointers and published coefficients stay
unchanged. The regression retains that exact queued-worker counterexample.
Returning roles can recover body status; they cannot silently revive the old
physics grant. Explicit qualified registration remains the recovery boundary.
An indeterminate collection instead defers the existing observer (`root=0`,
not ready, waiting); it fences old work without labelling the model absent and
retains the existing explicit renewal route after a healthy observation.

A fresh universal compile and all 22 native CTest suites passed, including the

and logs are under `Builds/claw-model-availability-20261118/normal-final/`. This
build reuses the recorded prior source-built CommonLib library and selects no
