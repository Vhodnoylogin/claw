# CLAW 0.11.0

Skin tone selects the base coat on the body. Hair colour selects the related coat materials on the head and fur where available. CLAW uses the installed Elegant textures and keeps an individual selection stable across transformations.
Improved coat recovery when the game recreates the werewolf's 3D. If a valid texture is temporarily unavailable to the renderer, CLAW keeps the existing material and retries the selection once.
Standalone NPC bodies can be supported by a separate compatibility patch for the specific NPC mod and body variant. The standard installer selects one default body family per sex.
The optional Faster HDT-SMP installer choice now animates the tail only. It requires a separate Faster HDT-SMP installation. Choose None to disable CLAW motion physics.
Human body shape has a stronger effect on female werewolf chest size. This applies to chest sliders for CBBE, 3BA and BHUNP and to the weight-driven contribution for Vanilla and UNP.

Install the [Elegant Player Only FOMOD 4K or 2K](https://www.nexusmods.com/skyrimspecialedition/mods/93336?tab=files)
with **Randomized** for individual coats. Other choices provide a single coat.
