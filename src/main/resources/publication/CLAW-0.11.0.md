# CLAW 0.11.0

Human hair colour selects a group of Elegant coats. Skin tone and an actor's stable seed help choose a variation. When hair colour is unavailable, known skin tone helps select a coat.
Improved coat recovery when the game recreates the werewolf's 3D. If a valid texture is temporarily unavailable to the renderer, CLAW keeps the existing material and retries the selection once.
Added support for explicit compatibility profiles for NPCs with custom bodies. Profiles require a known skin record and matching body resources.
Clarified that the Faster HDT-SMP installer option requires a separate Faster HDT-SMP installation. Choose None if that provider is absent.

Install the [Elegant Player Only FOMOD 4K or 2K](https://www.nexusmods.com/skyrimspecialedition/mods/93336?tab=files)
with **Randomized** for individual coats. Other choices provide a single coat.
