# CLAW 0.10.0

Optional motion physics affects ears and tails on both sexes, plus female
breasts. The installer offers None or Faster HDT-SMP. Install the selected
physics provider separately; the working archive contains CLAW's original
configuration and matching models, not the provider DLL or a contact system.

Human hair hue now selects a configured Elegant colour group. A stable actor
seed chooses a pattern within that group. Texture artwork remains supplied by
the separately installed Elegant Randomized option.

Use the [Nexus description](nexus/0.10.0/description.bbcode.txt) and
[changelog](nexus/0.10.0/changelog-0.10.0.txt) for publication. The
[modder guide](../../docs/modder-guide.md) is a separate GitHub release asset.
Runtime validation and its limits are recorded in
[the dated verification](../../../test/docs/release-0.10.0-2026-11-13.md).
