scene in Skyrim SE. The [published prerelease](https://github.com/Vhodnoylogin/claw/releases/tag/claw/se-core-20261030)

## Exact runtime scope

This baseline includes repaired body resources and deterministic human-to-wolf
linkage using ordinary human OBody presets. Both sexes, transformation/return,
human-key preservation, save/load and originally-beast assignments passed the
documented 117-check and 33-check SE runs. Official RaceMenu is used unchanged.
See [verification](../docs/verification-20261030.md). The included native DLL
accepts only Skyrim SE 1.7.104.0 / SKSE 2.3.1, with matching Address Library v13
and official compatible RaceMenu/SKEE. The FOMOD gates that optional native
selection to the exact game version and active `RaceMenu.esp`; its OBody host
also requires active `OBody.esp`. The installer cannot verify the complete
external dependency chain. Other runtimes receive base resources alone, without
a new game qualification claim. The retained base plugin is light-flagged, and
its VR loading requirements remain unqualified. A separate VR 1.4.15 DLL exists
as an offline compiled candidate; it is not a supported asset in this release.

The owner still finds the rendered wolf differences too weak. Numeric diversity
does not establish visible diversity: neutral limbs remain bulky, negative lean
inputs cannot produce a thinner endpoint, and the fur envelope hides part of
the skin deformation. These are acknowledged limits of the frozen result.
Breast naturalness, stronger thin/bulky endpoints, fur colour and physics belong
to subsequent development. Physics, VR and untested executable versions receive
no new compatibility claim.

## Installation consolidation

The two archives were installed through native MO2 installation and Downloads
accounting: 33 working files for HIMBO + 3BA with the OBody host, and eight test
files. These are now the only two CLAW mod folders. CLAW and the declared legacy
SE-Testing profile use them; Morphbench's enabled mod order remains unchanged.
All selected bytes, both profiles' winning runtime/configuration files, the
three required plugins and persisted archive provenance were independently
verified. Source archives remain outside the installed payload.

The first native removal of an old CLAW folder timed out without a successful
API response. Recovery stopped only the verified idle MO2 process, retained the
remaining folders outside MO2 and restarted MO2 without changing Bridge code.
All 16 original folders are recoverable from 281 byte-verified backup files
totalling 543,148,741 bytes; 15 also remain as retired folders outside MO2. The
original Polygon host was restored, independent settlement passed and only the
new preparation hold was cleared. This installation/recovery work started no
game and adds no runtime or visual acceptance.

External evidence: `Builds/claw-release-20261030/github-two-package-release-verified.json`
and `consolidation-20261030/FINAL-SETUP.json` beneath that build directory.
