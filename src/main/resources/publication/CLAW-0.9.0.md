# CLAW 0.9.0

CLAW reads the optional Elegant Randomized textures installed by the user.
Human hair colour and a stable actor seed select among ten available coats.
When the selected resources are unavailable the wolf retains its installed
skin. All textures come from the original author's downloads.

The installer includes classic UNP Renewal 4.6, body-mod links and OBody help.
The runtime also corrects human scale in ear, tail and claw proportions,
preserves human source data through loading and protects material changes
during opacity updates. Existing manual choices retain their logical coat IDs.

The [installation guide](runtime/README.md) describes the optional MO2 texture
installation and replacing the withdrawn package. Use the [Nexus description](nexus/0.9.0/description.bbcode.txt)
and [changelog](nexus/0.9.0/changelog-0.9.0.txt) for publication.
