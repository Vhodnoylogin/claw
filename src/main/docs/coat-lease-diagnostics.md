## Property alpha correction candidate, 6 November

The subsequent Q10 first-yield log observed one failed BODY field:
`propertyAlpha` changed from `0.92416644` to `1`. The log still does not identify
the writer. A finite per-geometry property fade is now separate from coat
content ownership. Material alpha, shader flags, textures, material/property/
guard identities and tint checks remain strict. Nonfinite property alpha refuses
ownership and restoration.

Rollback preserves the current finite property alpha. If the retained donor
already has that alpha it can be rebound unchanged. Otherwise rollback uses a
distinct donor-property clone with an independent engine-copied donor material,
initializes it on that geometry, then writes and checks the live alpha on the
clone. The shared donor property/material/extra data are never modified. Clone,
setup or readback failure retains the prior private binding and logs that donor
restoration was unavailable. A later replacement property or material is left
alone, including when setup returns failure; its alpha is not overwritten.

Native tests exercise the production content and rollback helpers, including
the exact Q10 transition and failure paths. They do not execute engine shader
initialization. A fresh full lifecycle game qualification remains necessary.
