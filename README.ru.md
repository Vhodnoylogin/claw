# CLAW — Customizable Lycanthrope Appearance and Weight

**CLAW** связывает морфы человеческого тела с телом вервольфа обоих полов.
Худой, атлетичный или полный человек получает соответствующую звериную форму.
В CLAW 0.8 есть матрицы для **HIMBO**, **CBBE**, **CBBE+3BA**, **BHUNP** и
ванильных тел обоих полов. OBody может предоставлять человеческие пресеты и персонажам,
впервые встреченным уже волками.

Во всех шести матрицах есть явный вход `$actor.weight`: вес актёра `0–100`,
нормализованный в `0–1`. Он не умножает повторно значения морфов RaceMenu.
Новый установщик независимо выбирает мужское и женское семейство; Vanilla
позволяет обойтись без заменителя человеческого тела. Доступные параметры лица
и роста влияют на голову, уши, хвост и когти; цвета кожи и волос тонируют материалы
вервольфа. Проверки установленного комплекта учитываются отдельно от наличия кода.

Рабочий мод устанавливается одним архивом FOMOD под именем
**CLAW**. Он содержит тела,
морфы, одну DLL CommonLib, матрицы и необязательный
модуль получения исходных данных OBody. Тестовые персонажи, физика и VR-тело
от первого лица в этот выпуск не входят.

## Установка и проверенный результат

Зависимости устанавливаются отдельными модами: выбранные тела, совместимый XP32,
соответствующие игре SKSE, RaceMenu/SKEE, Address Library и Microsoft Visual C++
x64 runtime. 3BA поддерживается как расширение CBBE. **Elegant Werewolf Replacer
нужен для текстур**; изменённые меши поставляет CLAW. Для автоматического
распределения пресетов нужны OBody и вся цепочка его зависимостей.

На мужском экране выберите HIMBO или Vanilla; на женском — CBBE, CBBE+3BA,
BHUNP 3.34 Advanced Ver4 или Vanilla. Для заменителей тела необходимы собранные
морфы. Для варианта BHUNP отдельно установите его зависимости, соберите тело с
Build Morphs и используйте совместимые текстуры кожи UNP. Заменители тела нужны
только для выбранной матрицы; для Vanilla они не требуются. Рекомендация по активным
плагинам не доказывает, какие меши фактически используются. После смены тела
нужно установить соответствующую матрицу; сохранённые настройки персонажа
не заменяются молча. Новая игра использует новые матрицы с самого начала;
переустановка варианта тела не сбрасывает сохранённую привязку персонажей.

[Технические проверки 0.8](src/main/docs/verification-20261102.md) на SE 1.7.104 /
SKSE 2.3.1 подтверждают работу Vanilla обоих полов: превращение, обновление
модели, сохранение/загрузку и возврат в человека. Прогон BHUNP/HIMBO также
прошёл все механические этапы и проверку 47 реальных входов BHUNP, после чего
игра завершилась аварийно при окончании сеанса. Общий результат этого прогона
остаётся неуспешным; причина завершения не установлена. Более ранние проверки
HIMBO/3BA и диких вервольфов сохранены отдельно. Одна DLL предназначена для
SE, AE и VR; прогоны SE не подтверждают работоспособность движков AE и VR.
[Границы совместимости](src/main/docs/universal-runtime.md) отделены от
результатов конкретного прогона.

Нейтральные `_0` и `_1` каждого пола пока одинаковы: разнообразие дают морфы.
Улучшение груди, живота и мускулатуры, вариативность рисунка шерсти,
физика, коллизии и VR-тело описаны в
[беклоге](src/main/docs/roadmap.md).

## Исходники и сборка

```text
src/main/cpp/                  DLL и общее вычислительное ядро
src/main/python/               сборщики, физика и подготовка VR
src/main/papyrus/              исходники игровых скриптов
src/main/resources/            доноры, рецепты, YAML, матрицы и материалы страницы
src/main/docs/                 документация
src/test/                      все тесты, сцены, пресеты и тестовые ресурсы
target/                        результаты сборки; исключены из Git
```

В Git хранятся исходники и необходимые авторские ресурсы с происхождением и
разрешениями. DLL, PEX, скомпилированные ESP, готовые NIF/TRI и архивы,
воспроизводимые сборкой, остаются в `target/` или указанном внешнем каталоге.
Готовые архивы публикуются как файлы релиза. LFS не меняет это правило.

Начните с [инструкции сборки](src/main/docs/rebuild.md) и настройте локальные пути
в исключённом из Git `build.local.json`. Свежая сборка из трёх оригинальных
доноров с Blender 5.2.3 воспроизвела все шесть ресурсов тел версии 0.7 побайтово.
Нового игрового прогона это не добавляет: прежние результаты относятся к
выпущенному комплекту. [Правила выпуска](src/main/docs/release-workflow.md)
задают проверку архива, веток и очистку временных файлов.

Игра и отдельный [плагин сравнения для Morphbench](https://github.com/Vhodnoylogin/claw-morphbench-plugin)
используют [одно ядро матриц](src/main/docs/matrix-contract.md). Плагин развивается
в собственном репозитории и подключает закреплённую зависимость; он не является
игровой зависимостью CLAW. Ранее выпущенная версия 0.3 рассчитана на матрицы
CLAW 0.7; обновлённая версия инструмента для матриц 0.8 пока не выпущена.

Релизные исходники вместе с `src/test/` находятся в `main`; дальнейшая разработка
ведётся в одной рабочей ветке. Исторические теги и архивы сохраняются.
Основной репозиторий: [Vhodnoylogin/claw](https://github.com/Vhodnoylogin/claw).
